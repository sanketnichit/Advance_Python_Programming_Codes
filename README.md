# Advanced Python Programming

A collection of Python examples covering **object-oriented programming, design patterns, decorators, dynamic programming, regular expressions, file handling, and small application-oriented programs**.

## Topics Covered

### Algorithms

Examples of dynamic programming techniques:

- Fibonacci using dynamic programming
- 0/1 Knapsack
- Longest Common Subsequence (LCS)

### Design Patterns

Examples of common object-oriented design patterns:

- Factory
- Observer
- Singleton
- Strategy

### Decorators

Practical decorator examples for:

- Function call counting
- Function logging
- Input validation
- Login authentication

### Regular Expressions

- Email extraction and validation using Python regular expressions

### File and Data Processing

- Basic file handling
- CSV-to-JSON conversion

### Application Examples

- Security incident report generator
- Payment processing system
- Library management system

## Running the Examples

Each example is a standalone Python script.

From the repository root:

```bash
python path/to/example.py
```

For example:

```bash
python algorithms/fibonacci_dynamic_programming.py
```

Some programs are interactive and accept input from the terminal.

## Purpose

This repository serves as a learning collection for advanced Python programming concepts and classroom/laboratory practice. The examples are intentionally small so individual concepts can be studied and executed independently.
